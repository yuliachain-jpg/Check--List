## Как устроены чек-листы

Каждый чек-лист структурирован по элементам пользовательского интерфейса.

Проверки сформулированы кратко и понятно, в формате «Проверить…».

## Что покрывают чек-листы

- **Позитивные сценарии** — проверка корректных данных и штатной работы функциональности.
- **Негативные сценарии** — пустые поля, неверный формат данных, двойное нажатие.
- **Граничные значения** — минимальные и максимальные значения, значения за пределами допустимого диапазона.
- **Проверка сохранения состояния** — перезапуск приложения, поворот экрана, сохранение введённых данных.

## Навыки и техники
