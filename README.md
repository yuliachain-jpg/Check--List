Как устроены чек-листы:

В каждом чек-листе разделы идут по элементам интерфейса, а проверки сформулированы кратко: 
"Проверить …" .

Что покрыто:

• позитивные сценарии (корректные данные)
• негативные сценарии (пустые поля, •неверный формат, двойное нажатие, нет интернета)
• граничные значения (минимум, максимум, значения за границами)
• сохранение состояния (перезапуск приложения, поворот экрана.
